## نظرة عامة (Overview)

تتحقق هواتف الآيفون من وجود البطارية وبياناتها الحرارية وسجلات دائرة القياس (`Smart Battery`) لحظة الإقلاع وبشكل دوري أثناء التشغيل. عند تغذية اللوحة الأم من الباور سبلاي عبر أطراف الطاقة فقط (`B+` و `GND`) دون اتصال بيانات البطارية، تظهر المشاكل التالية:

- فشل الإقلاع أو الدخول في حلقة إعادة تشغيل مستمرة (`Boot Loop`)
- **إعادة تشغيل تلقائية كل 3 دقائق** (`Userspace watchdog timeout` / فقدان قراءة مستشعرات البطارية)
- تقييد أداء المعالج وتعطّل مسارات الشحن أثناء تتبع الأعطال

يعمل **CHIPLER Battery Emulator** كحلقة وصل ذكية بين الباور سبلاي وفلاتة البطارية على اللوحة الأم. يعتمد الجهاز على متحكم **Raspberry Pi RP2350** ثنائي النواة لمحاكاة بروتوكول بطاريات أبل (`SMBus 1.8V`) في الوقت الفعلي عبر محرك التعلم الذاتي (**Auto-Learn Engine**)، مما يتيح إقلاع الهاتف باستقرار تام والتحكم اللحظي في نسبة الشحن من **1% إلى 100%** دون الحاجة لبطارية أصلية.

## المميزات الرئيسية (Key Features)

- **محاكاة كاملة لبروتوكول بطاريات أبل (`SMBus 1.8V`):** استجابة حية لكافة سجلات Veridian القياسية (`0x0B`) الخاصة بالجهد، التيار، الحرارة، السعة التصميمية، وبيانات التحقق، مع حساب تلقائي لبايت فحص الأخطاء (**PEC / CRC-8**) بزمن استجابة في حدود الميكروثانية.
- **محرك التعرف الذاتي (`AUTO LEARN Engine`):** يبدأ المحاكي فور التشغيل في وضع الاستماع الصامت (`LISTEN`) لمراقبة الناقل، ويتعرف تلقائياً على بصمة تسلسل طلبات دائرة إدارة الطاقة (`PMU`) ليطابق البروفايل المناسب (`COMPATIBLE`) وينتقل إلى وضع التشغيل (`RUNNING`) دون اختيار يدوي لموديل الهاتف.
- **تحكم لحظي في نسبة الشحن (`Dynamic SOC Control`):** تعديل نسبة البطارية مباشرة بين **1% و 100%** عبر شاشة اللمس الملونة أو أوامر `USB Serial`، وانعكاس النسبة فوراً داخل نظام iOS وشريط الحالة دون إعادة تشغيل الهاتف.
- **عزل كهربي آمن (`Safe 1.8V Level Shifting`):** حماية كاملة للمعالج وآيسي الباور (`PMU`) عبر محول مستويات ثنائي الاتجاه بترانزستورات **`BSS138` N-MOSFET**، ومقاومات رفع متوازنة (`4.7kΩ` لجهة الهاتف و`10kΩ` لجهة المتحكم) مع منظم خطي **`AMS1117-1.8V`** مدعوم بمكثف تانتالوم `22µF` ومقاومة حمل دائم `150Ω` لمنع تجاوز الجهد `1.8V`.
- **مراقبة دقيقة للقدرة (`Power & Current Telemetry`):** شريحة **`INA226`** مدمجة على ناقل `I2C` داخلي مستقل (`3.3V`) مع مقاومة شنت `5mΩ` لقياس وعرض الجهد وتيار الاستهلاك لحظياً حتى **`5A`**.

## بنية الهاردوير (Hardware Architecture)

### المواصفات الأساسية

| المكون | المواصفة الفنية |
| :--- | :--- |
| **المتحكم الدقيق (MCU)** | Raspberry Pi RP2350 (Dual-Core Arm Cortex-M33) |
| **بروتوكول الاتصال** | Apple Smart Battery SMBus (`0x0B` Veridian + PEC/CRC-8) |
| **مواءمة مستوى الإشارة** | `1.8V` ثنائي الاتجاه (`BSS138` + `AMS1117-1.8V` + `4.7kΩ / 10kΩ` Pull-ups) |
| **مستشعر القياس الداخلي** | `INA226` على ناقل `3.3V I2C` مستقل مع مقاومة شنت `5mΩ` (حتى `5A`) |
| **واجهة العرض والتحكم** | شاشة لمس ملونة `SPI TFT` + منفذ تحكم `USB CDC Serial` |
| **جهد التشغيل (Bench PSU)** | `4.0V DC` (حد تيار موصى به: `2.5A`) |

### جدول التوصيلات السريعة (Quick Pinout)

| القطعة | الطرف | يتصل بـ (المتحكم / البريد بورد) | الجهد | الوظيفة |
| :--- | :--- | :--- | :--- | :--- |
| **RP2350** | `3V3` | خط تغذية البريد بورد (`3.3V Rail`) | `3.3V` | تغذية الشاشة + حساس `INA226` + دخل `AMS1117` |
| **RP2350** | `GND` | خط الأرضي العام المشترك | `0V` | أرضي موحد للدائرة والهاتف |
| **RP2350** | `GP0` | طرف `T_DO` بالشاشة | `3.3V` | قراءة إحداثيات اللمس (`SPI MISO`) |
| **RP2350** | `GP1` | طرف `CS` بالشاشة | `3.3V` | اختيار شريحة الشاشة (`LCD Chip Select`) |
| **RP2350** | `GP2` | طرف `SCK` و `T_CLK` بالشاشة | `3.3V` | ساعة التزامن المشتركة (`SPI Clock`) |
| **RP2350** | `GP3` | طرف `SDI` و `T_DIN` بالشاشة | `3.3V` | خط البيانات المشترك (`SPI MOSI`) |
| **RP2350** | `GP4` | طرف `RESET` بالشاشة | `3.3V` | نبضة إعادة ضبط الشاشة (`Hardware Reset`) |
| **RP2350** | `GP5` | طرف `DC/RS` بالشاشة | `3.3V` | تبديل الأوامر والبيانات للشاشة |
| **RP2350** | `GP6` | طرف `Drain` لـ `Q1` (`BSS138`) | `3.3V` | بيانات البطارية `SMBus SDA` (مع مقاومة `10kΩ` لـ `3.3V`) |
| **RP2350** | `GP7` | طرف `Drain` لـ `Q2` (`BSS138`) | `3.3V` | ساعة البطارية `SMBus SCL` (مع مقاومة `10kΩ` لـ `3.3V`) |
| **RP2350** | `GP8` | طرف `SDA` بحساس `INA226` | `3.3V` | ناقل بيانات قراءة الجهد والتيار الداخلي |
| **RP2350** | `GP9` | طرف `SCL` بحساس `INA226` | `3.3V` | ساعة ناقل قراءة الجهد والتيار الداخلي |
| **RP2350** | `GP10` | طرف `ALERT` بحساس `INA226` | `3.3V` | مقاطعة تحذير تجاوز التيار (`Internal Pull-Up`) |
| **RP2350** | `GP26` | طرف `T_CS` بالشاشة | `3.3V` | اختيار شريحة اللمس (`Touch Chip Select`) |
| **RP2350** | `GP27` | طرف `T_IRQ` بالشاشة | `3.3V` | مقاطعة لمس الشاشة (`Touch Interrupt`) |
| **AMS1117** | `VOUT (Pin 2)` | خط `1.8V` بالبريد بورد | `1.8V` | تغذية بوابات `Q1`/`Q2` ومقاومات `4.7kΩ` لجهة الهاتف |
| **Q1 Source** | `Pin 2` | خط **`SDA`** بفلاتة الآيفون | `1.8V` | خط بيانات البطارية للهاتف (مع مقاومة `4.7kΩ` لـ `1.8V`) |
| **Q2 Source** | `Pin 2` | خط **`SCL`** بفلاتة الآيفون | `1.8V` | خط ساعة البطارية للهاتف (مع مقاومة `4.7kΩ` لـ `1.8V`) |

> **دليل التجميع المصور:** لتنفيذ الدائرة خطوة بخطوة على البريد بورد، راجع الدليل الكامل في [`docs/CHIPLER_Assembly_AR.pdf`](docs/CHIPLER_Assembly_AR.pdf) (يحتوي على صور القطع المعتمدة، قائمة المكونات `BOM`، رسومات اتجاهات الأيسيهات، وجدول التوصيل السلكي الملون).

## البدء والتشغيل (Getting Started)

### الخيار الأول: شحن الفيرموير الجاهز مباشرة (موصى به)

1. اضغط باستمرار على زر **`BOOTSEL`** على بوردة `RP2350` أثناء توصيلها بالكمبيوتر عبر كابل USB، ثم اترك الزر ليظهر قرص التخزين **`RPI-RP2`**.
2. انسخ ملف الفيرموير الجاهز [`firmware/releases/CHIPLER_AUTO_LEARN_P1_RC1_fd0c96b.uf2`](firmware/releases/CHIPLER_AUTO_LEARN_P1_RC1_fd0c96b.uf2) وضعه داخل قرص **`RPI-RP2`**.
3. ستعيد البوردة التشغيل تلقائياً وتظهر لوحة القياسات على الشاشة في وضع الاستماع **`LISTEN`**.

### الخيار الثاني: بناء الكود من المصدر (Building from Source)

1. **نسخ المستودع:**
   ```bash
   git clone [https://github.com/Hamedlasheen/CHIPLER-Battery-Emulator.git](https://github.com/Hamedlasheen/CHIPLER-Battery-Emulator.git)
   cd CHIPLER-Battery-Emulator/firmware/source
   ```

2. **تجميع الكود وإنتاج ملف `.uf2` (يتطلب Pico SDK و ARM GCC):**
   ```bash
   mkdir build && cd build
   cmake -DPICO_BOARD=pico2 -DPICO_PLATFORM=rp2350 ..
   make -j4
   ```

## تعليمات الاستخدام الآمن على الباور سبلاي

> **تحذير:** تأكد دائماً من ضبط جهد الباور سبلاي بدقة قبل توصيل أي لوحة أم. تجاوز جهد **4.4V** على خط `B+` قد يؤدي إلى تلف دائم في آيسي الباور (`PMU`) ودوائر الشحن.

1. اضبط الباور سبلاي الخارجي على جهد **`4.0V`** وحد تيار **`2.5A`**.
2. مرّر خرج الباور سبلاي عبر حساس `INA226` إلى أطراف الطاقة بفلاتة بطارية الآيفون (`B+` و `GND`).
3. وصّل خطي البيانات (`SDA` و `SCL` الخارجين من دائرة العزل `1.8V`) بالأطراف المقابلة في فلاتة البطارية.
4. اضغط زر تشغيل الآيفون؛ سيتعرف المحاكي تلقائياً على الهاتف، وتتحول الشاشة إلى وضع **`RUNNING`** مع ظهور نسبة الشحن فوراً على شاشة الهاتف.

## التحقق والاختبارات (Verification & Testing)

- **اختبارات الوحدات (`CTest`):** اجتياز **35/35** جناح اختبار بنجاح تام في **1.19 ثانية**.
- **محرك التعلم (`AUTO LEARN`):** التحقق من **225** حالة فحص لبصمات البروتوكول وحفظ البروفايلات في الذاكرة بنظام `Fail-Closed`.
- **استقرار الواجهة (`UI State Machine`):** اجتياز **7,886** فحص لمسارات التحكم باللمس وإدارة الحالات.
- **التحقق الميداني:** إقلاع مستقر لموديلات الآيفون المستهدفة وتحديث نسبة الشحن لحظياً من `1%` إلى `100%` دون أخطاء ناقل أو إعادة تشغيل.
